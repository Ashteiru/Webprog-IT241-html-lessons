Resources Used

The following resources were used in the development of this profile website:

  • MDN Web Docs (Mozilla Developer Network) – Used as the primary reference for HTML5 semantic elements (header, main, footer).
  • MDN CSS Flexible Box Layout – Reference for implementing the layout structure in flexbox-grid.css.
  • MDN CSS Grid Layout – Reference for the main container grid system used in the CSS.
  • MDN JavaScript Event Reference – Guide for implementing the click and DOMContentLoaded event listeners in script.js.
  • W3C HTML Validator – Used to validate the markup structure.
  • W3C CSS Validator – Used to validate stylesheet syntax.
  • Vue.js 3 (CDN) – Progressive JavaScript framework used for reactive data binding and displaying the skills list dynamically.
